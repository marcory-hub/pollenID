# Ranunculaceae (ranonkelfamilie)

De familie splijt in Beug over **meerdere pollenklassen**: vooral tricolpaat–psilaat/scabraat (hfst. 13: *Ranunculus acris*-type, *Aconitum*-groep, *Nigella*) en periporaat (hfst. 33: *Anemone*, *Thalictrum*, enkele *Ranunculus*). Niveau 1-anker: `ranunculus_typ`.

## Type-overzicht

| Type | Kenmerk | Beug |
| :--- | :--- | :--- |
| ***Ranunculus acris*-type** | tricolpaat; microechini op columellae | 13.32 ([Beug 13](../../Identificatiesleutels/beug13-tricolpatae-ps.md)) |
| ***Aconitum*-groep** | tricolpaat–psilaat; *Aquilegia* / *Aconitum* / *Consolida* | [13.4](../../Identificatiesleutels/beug13-tricolpatae-ps-aconitum-groep.md) |
| ***Nigella*** | tricolpaat; dikke exine; scabraat–microechinaat | 13.29 |
| ***Anemone*** | Beug 33.22 periporaat (*A. coronaria*); atlas `anemone_typ` = tricolpaat | [33.22](../../Identificatiesleutels/beug33-periporatae-anemone.md) |
| ***Thalictrum*** | periporaat; scabraat | [33.25](../../Identificatiesleutels/beug33-periporatae-thalictrum.md) |
| ***Ranunculus arvensis*-groep** | periporaat (aparte *Ranunculus*-tak) | [33.3](../../Identificatiesleutels/beug33-periporatae-ranunculus.md) |
| ***Clematis*** | tricolpaat–scabraat [to be verified: Beug-eindpunt] | — |
