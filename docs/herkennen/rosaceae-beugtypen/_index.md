# Rosaceae (rozenfamilie)

Determinatie afgeleid van **Beug hoofdstuk 20** (Tricolporoidatae, striate sculptuur), met aanvullingen uit andere Beug-hoofdstukken voor *Sanguisorba*, *Alchemilla* en *Filipendula*.

Speciale sleutels: [Reitsma 1966](../../Identificatiesleutels/rosaceae-reitsma.md), [Eide 1981](../../Identificatiesleutels/rosaceae-eide.md). Beug 20-overzicht: [Tricolporoidatae striaat](../../Identificatiesleutels/beug20-tricolporoidatae-str.md).

## Type-overzicht

| Type | Kenmerk | Beug |
| :--- | :--- | :--- |
| **Agrimonia**-type | groot, prolaat–perprolaat; transversale wallen equatoriaal; tectum golvend | [20.4](../../Identificatiesleutels/beug20-tricolporoidatae-str-agrimonia.md) |
| **Potentilla**-type | opercula + vesiculae equatoriaal (*Potentilla*, *Fragaria*) | [20.5](../../Identificatiesleutels/beug20-tricolporoidatae-str-potentilla.md) |
| **Rosa** | opercula aanwezig, niet zo verdikt als bij Potentilla; geen vesiculae | [20.6](../../Identificatiesleutels/beug20-tricolporoidatae-str-rosa.md) |
| **Aruncus**-type | klein (ca. 11–21 µm); *Aruncus*, *Spiraea* | [20.10](../../Identificatiesleutels/beug20-tricolporoidatae-str-aruncus.md) |
| **Geum**-type | equatoriale opwölvingen **zonder** opercula (*Geum*, *Sibbaldia*, *Waldsteinia*) | [20.11](../../Identificatiesleutels/beug20-tricolporoidatae-str-geum.md) |
| **Sorbus**-groep | striaat fruit-/struikcluster; met/zonder perforaties; catch-all «Rosaceae indet.» | [20.12](../../Identificatiesleutels/beug20-tricolporoidatae-str-sorbus.md) |
| **Sanguisorba** | twee pollenklassen: 3-colporaat (*S. minor*) vs 6-colporaat (*S. officinalis*) | 13.7 / 25.15 |
| **Filipendula** | scabraat–microechinaat; colpi equatoriaal vernauwd | 14.24 |

### Rosaceae indet. en lookalikes

- **Rosaceae indet.**: vorm/aperturen als *Prunus*/*Sorbus*, maar zonder herkenbare striate sculptuur en zonder perforaties (psilaat of scabraat). Geen aparte fotogalerij.
- ***Lycium*** (Solanaceae): in Beug 20.12 als lookalike binnen dezelfde groep; geen Rosaceae.
