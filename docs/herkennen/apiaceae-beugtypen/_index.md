# Apiaceae (schermbloemenfamilie)

Determinatie afgeleid van **Beug 14.11** (Tricolporatae psilaat, schermbloemen): prolate korrels, colpi met transversale poriën, en vooral verschillen in **columellae-laag** (polair vs equatoriaal), **CL-index** en **C-/IC-contour**.

Interactieve sleutel: [Beug 14.11 Apiaceae](../../Identificatiesleutels/beug14-tricolpatae-ps-apiaceae.md).

## Type-overzicht

| Type | Kenmerk | Beug |
| :--- | :--- | :--- |
| **Heracleum** | columellae polair langer dan equatoriaal | [14.11.2](../../Identificatiesleutels/beug14-tricolpatae-ps-apiaceae.md) |
| **Conium**-type | columellae equatoriaal duidelijk langer dan polair | 14.11.6 |
| **Astrantia**-type | groot, hoge CL-index; dunne contrastarme columellae | 14.11.9 |
| **Eryngium** | C-zijde convex / «boemerang»; exine gelijkmatig dun | 14.11.12 |
| **Daucus**-type | C-zijde recht; A-/I-contour vaak ingezonken | 14.11.18 |
| **Anthriscus** e.a. | kleinere schermbloemen; type vaak op genusniveau | 14.11 (diverse eindpunten) |
