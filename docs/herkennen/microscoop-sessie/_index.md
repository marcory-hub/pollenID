# Microscoop-sessie

Sessiekaart voor live LM. Geen atlasbeelden: alleen beslissingsregels.

## Werkwijze

1. Kies vijf taxa uit de tabel (of de startrij).
2. Noteer per korrel: sculptuur, apertuur, grootteband, dan pas een naam.
3. Log verwarringen in je eigen notitieboek.
4. Op de site: [Willekeurig](../../naslag/palynoquest.md) → Kenmerken / Lookalike; knop **Exporteer verwarringen**.
