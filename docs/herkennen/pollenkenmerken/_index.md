# Pollenkenmerken

Algemene kenmerken om pollen te beschrijven: **vorm**, **apertuur**, **sculptuur** en **grootte**. Voorbeelden komen uit de herkennen-pagina's (Niveau 1-families + Asteraceae/Rosaceae). Letter-typen (A/C/H/J/S/T) bestaan alleen bij [Composieten](../composieten-abchjst/_index.md).

## Vorm

| Term | Kenmerk | Voorbeeld |
| :--- | :--- | :--- |
| **Prolaat** | langwerpiger in polaire as | Apiaceae (*Heracleum*, *Anthriscus*) |
| **Sferoïdisch** | ongeveer bolvormig | *Tilia*, veel *Ranunculus* |
| **Perprolaat** | sterk verlengd | veel Apiaceae |

## Apertuur

Openingen in de exine (colpi = groeven; poriën = ronde openingen).

| Term | Kenmerk | Voorbeeld |
| :--- | :--- | :--- |
| **Inaperturaat** | geen aperturen | *Populus* ([Salicaceae](../salicaceae-beugtypen/_index.md)) |
| **Tricolpaat** | 3 colpi | *Acer*, *Salix*, *Brassica*, *Ranunculus acris*-type |
| **Tricolporaat** | 3 colpi + porus | *Tilia*, *Trifolium*, *Vicia* |
| **Tricolporoidaat** | colpi equatoriaal vernauwd / porus onduidelijk | *Robinia*, *Cytisus* |
| **Periporaat** | vele poriën over het oppervlak | *Anemone*, *Thalictrum*, *Malva* |
| **Triporaat** | 3 poriën | *Phaseolus* |
| **Tetrade** | vier korrels verbonden | *Calluna* (Ericaceae; Niveau 2) |

## Sculptuur

Oppervlaktereliëf van de exine (helderveld / fasecontrast).

| Term | Kenmerk | Voorbeeld |
| :--- | :--- | :--- |
| **Psilaat** | glad / bijna glad | veel Apiaceae in LM |
| **Scabraat / verrucaat** | fijne oneffenheden / wratten | *Ranunculus*, *Heracleum* |
| **Reticulaat** | netwerk (muri + lumina) | *Salix*, *Brassica*, *Tilia* |
| **Striaat** | evenwijdige wallen (valla) | *Acer*, Rosaceae (*Prunus*) |
| **Echinaat** | stekels | Asteraceae ([ABCHJST](../composieten-abchjst/_index.md)); *Malva* |
| **Fenestraat** | openingen («ramen») tussen stekels | *Taraxacum*-type (Cichorieae) |

## Grootte

Meet de **grootste as** (µm). Orde van grootte (indicatief):

| Klasse | Bereik | Voorbeelden |
| :--- | :--- | :--- |
| Klein | ca. &lt; 20 µm | *Myosotis*, sommige *Salix* |
| Middel | ca. 20–40 µm | *Brassica*, *Trifolium repens*, *Acer* |
| Groot | ca. 40–70 µm | *Heracleum*, *Astrantia*, *Tilia* |
| Zeer groot | &gt; 70 µm | *Malva*, *Abelmoschus* |

True-scale weergave op deze site: `pollen_img` (schaal via `data/pollen.yaml`).
