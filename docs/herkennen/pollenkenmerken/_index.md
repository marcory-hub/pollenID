## Apertuur

Openingen in de exine (colpi = groeven; poriën = ronde openingen).

| Term | Kenmerk | Voorbeeld |
| :--- | :--- | :--- |
| **Inaperturaat** | geen aperturen | *Populus* ([Salicaceae](../salicaceae-beugtypen/_index.md)) |
| **Tricolpaat** | 3 colpi | *Acer*, *Salix*, *Brassica*, *Ranunculus acris*-type |
| **Tricolporaat** | 3 colpi + porus | *Tilia*, *Trifolium*, *Vicia* |
| **Tricolporoidaat** | colpi equatoriaal vernauwd / porus onduidelijk | *Robinia*, *Cytisus*, *Prunus* |
| **Periporaat** | vele poriën over het oppervlak | *Thalictrum*, *Plantago*, *Silene*, *Malva* |
| **Triporaat** | 3 poriën | *Phaseolus*, *Urtica* |
| **Tetrade** | vier korrels verbonden | *Calluna* (Ericaceae; Niveau 2) |

Note: `anemone_typ` in YAML is `3-4-colpaat`; de atlasbeelden van *A. blanda* tonen drie colpi. Beug 33.22 (*A. coronaria*) is periporaat, maar die soort heeft hier nog geen PNG. Periporaat-voorbeelden hieronder: *Thalictrum*, *Plantago*, *Silene*, *Malva*.

## Sculptuur

Oppervlaktereliëf van de exine (helderveld / fasecontrast).

| Term | Kenmerk | Voorbeeld |
| :--- | :--- | :--- |
| **Psilaat** | glad / bijna glad | *Nigella*, *Filipendula*, veel Apiaceae in LM |
| **Scabraat / verrucaat** | fijne oneffenheden / wratten | *Ranunculus*, *Heracleum* |
| **Reticulaat** | netwerk (muri + lumina) | *Salix*, *Brassica*, *Tilia* |
| **Striaat** | evenwijdige wallen (valla) | *Acer*, Rosaceae (*Prunus*, *Rosa*) |
| **Echinaat** | stekels | Asteraceae (composietenfamilie) ([ABCHJST](../composieten-abchjst/_index.md)); *Malva* |
| **Fenestraat** | openingen («ramen») tussen stekels | *Taraxacum*-type (Cichorieae) |

## Grootte

Meet de **grootste as** (µm). Orde van grootte (indicatief). Beelden true-scale via `pollen_img` (schaal uit `data/pollen.yaml`).

| Klasse | Bereik | Voorbeelden |
| :--- | :--- | :--- |
| Klein | ca. &lt; 20 µm | *Myosotis*, *Filipendula*, *Salix* |
| Middel | ca. 20–40 µm | *Brassica*, *Trifolium repens*, *Acer* |
| Groot | ca. 40–70 µm | *Eryngium*, *Nigella*, *Astrantia* |
| Zeer groot | &gt; 70 µm | *Malva*, *Abelmoschus*, *Echinops* |
