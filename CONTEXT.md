# PollenID

Dutch melissopalynology reference and learning site: morphology, keys, and recognition training.

## Language

**Pollentype**:
A morphology bucket used for reporting and grouping. Membership in the same pollentype does not by itself prevent a lookalike link.
_Avoid_: pollen type (as a separate concept)

**Lookalike**:
A relation between different training units (species and/or pollentypes) whose pollen look almost the same under LM, so a determination error can occur easily. Includes within-type species pairs when species-level mix-up is a learning goal.
_Avoid_: Verwarring, confusable-pairs, look-a-like (as product/mode name)
